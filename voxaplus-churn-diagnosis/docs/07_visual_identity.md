# Voxa+ — Visual Identity

**Document status:** Phase 5 deliverable.
**Assets:** `assets/brand.py` (palette + type, the single source of truth),
`assets/gen_logo.py` (emits the mark, wordmark and page backgrounds),
`powerbi/theme/theme.json` (passes `pbir theme validate`),
`powerbi/assets/` (generated PNGs + `_page_heights.json`).

---

## 1. Tone

Corporate, restrained, board-facing. Voxa+ is a streaming service, so the identity is
media-adjacent — a play glyph, a confident violet — but this is a **churn diagnosis for the
board**, not a marketing page. No gradients on data, no glow, no more than one accent
colour competing for attention at a time.

payback (a *decrease* is `#2E7D5B` good); the waterfall bridges use the same
`#2E7D5B` / `#C0453B` sentiment pair as the KPI deltas.

## 4. The signature element (every page)

A full-page **background PNG** (`powerbi/assets/bg_<page>.png`, generated by `gen_logo.py`),
because a bound image visual does not render reliably through a hand-generated PBIR:

1. **Deep-violet band** (`#241348`, 60 px) with the **Voxa+ wordmark** left and a quiet
   "Subscriber Churn Diagnosis" label right.
2. **Amber hairline** (`#E6A23C`, 3 px) directly under the band.
3. On the light body: the **page title + one-line business question**, then a faint rule.

On top of the PNG, every page places, in this order:
- **Currency** slicer + **Market** slicer (top-right, on the band zone).
- **Analysis-Period** date slicer (joined on `order`/`month` keys, never an Advanced
  `dim_date` filter — guardrail).
- One row of **six KPI cards**: a single-measure value card + a small "vs Target" delta card,
  both transparent / no border / no shadow, sitting on a **white rounded frame `shape`**
  (corner radius 20, no shadow). Delta green if better / red if worse, inverted for
  lower-is-better metrics.
- Two content rows on the **3-30-300** gradient (glance → scan → study).

Per-page heights (`powerbi/assets/_page_heights.json`): **Executive = 900**, all others
**720** — so adding visuals to the exec page never stretches the rest.

## 5. Theme (`powerbi/theme/theme.json`)

`visualStyles` for ~20 visual types + `page`. Highlights:

- Charts: white surface, 8 px rounded border, **soft drop shadow** (violet-tinted, 88 %
  transparent) — **only on charts**, never on cards, frames, slicers, shapes or images.
- Gridlines: horizontal only, `#E7E5EF`, 1 px; category axis gridlines off; axis titles off
  by default.
- Data labels **on** at theme level for bar / column / line / combo / waterfall; **off** for
  stacked and area (dense series get a per-visual override in Phase 8).
- `card`: category label shown small and muted, value 30 pt semibold, no background/border
  (the frame `shape` provides the surface).
- `slicer`: no header, no border, transparent; title muted 9 pt; single-select default.
- `waterfallChart`: sentiment colours pinned to good/bad/violet.
- `tableEx` / `pivotTable`: horizontal rules only, violet-tinted header fill, 9 pt.

## 6. Regenerating

```
python assets/gen_logo.py          # mark, wordmark, 7 page backgrounds, _page_heights.json
pbir theme validate powerbi/theme/theme.json
```
