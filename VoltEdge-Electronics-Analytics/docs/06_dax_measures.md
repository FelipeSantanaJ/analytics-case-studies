# 06 — DAX Measure Library

_Generated by `etl/gen_dax_doc.py` from `etl/pbi_measures.py`, which is also the source `etl/gen_semantic_model.py` writes into the `_Measures` table of the TMDL model._

**167 measures** in **14 display folders**. All monetary measures are USD (the reporting currency); `*_local` columns remain on detail tables. Sales measures exclude cancelled orders. Time intelligence runs on `dim_date[date]` (contiguous daily, auto date/time disabled).

## Conventions

| Suffix / prefix | Meaning |
|---|---|
| `(USD)` | Amount in US dollars (reporting currency) |
| `(Rpt)` | Amount converted to the currency chosen in the *Reporting currency* slicer |
| `PY` | Same measure, same-period-last-year |
| `YoY` / `YoY %` | Current − PY, and that over PY |
| `(Comparable Base)` | Restricted to markets live for the whole CY+PY span (US) — the like-for-like cut |
| `(Expansion)` | Total − Comparable Base |

## Key definitions

- **Net Revenue** = Gross Revenue − Discounts − Returns  (`Gross Sales − Returns`).
- **Gross Profit** = Net Revenue − COGS (moving-average cost). Returns reduce revenue by the refund; the COGS of restocked goods is not added back, so margin is a conservative estimate.
- **Contribution Margin** = Gross Profit − Marketing Spend − Shipping Cost − Total Payment Cost.
- **Cash Conversion Cycle** = DIO + DSO − DPO, from `fact_inventory_snapshot`, `fact_payment_schedule` and `fact_purchase_orders` respectively.

```dax
Exec Insight =
VAR _nr    = [Net Revenue (USD)]
VAR _yoy   = [Net Revenue YoY %]
VAR _yoyC  = [Net Revenue YoY % (Comparable Base)]
VAR _gm    = [Gross Margin %]
VAR _cm    = [Contribution Margin %]

VAR _ot    = [On-Time Delivery %]

VAR _dir   = IF ( _cmT >= -0.01, "at break-even", IF ( _cmT >= -0.05, "closing on break-even", "still loss-making" ) )
RETURN
    "Net revenue " & FORMAT ( _nr / 1000000, "$#,0.0" ) & "M"
    & IF ( ISBLANK ( _yoy ), "", ", " & FORMAT ( _yoy, "+0.0%;-0.0%" ) & " YoY (" & FORMAT ( _yoyC, "+0.0%;-0.0%" ) & " like-for-like)" )
    & IF ( ISBLANK ( _tgt ), "", ", " & FORMAT ( _tgt, "+0.0%;-0.0%" ) & " vs plan" ) & ".  "
    & "Gross margin " & FORMAT ( _gm, "0.0%" ) & "; contribution margin " & FORMAT ( _cm, "0.0%" )
    & " (" & FORMAT ( _cmT, "0.0%" ) & " trailing-12m, " & _dir & ").  "
    & "Blended CAC " & FORMAT ( _cac, "$#,0" ) & ", repeat rate " & FORMAT ( _rep, "0.0%" )
    & ", on-time delivery " & FORMAT ( _ot, "0.0%" ) & "."
```
