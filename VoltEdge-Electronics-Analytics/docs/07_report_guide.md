# 07 — Report Guide

The Power BI report is a **thick `.pbip` project**: a local semantic model (TMDL, generated
from the curated Parquet schemas) plus a PBIR report. Open
`powerbi/VoltEdge Electronics.pbip` in Power BI Desktop; it imports
`data/curated/*.parquet` through the `pDataFolder` parameter and applies the 145 measures.

- **Model:** `etl/gen_semantic_model.py` → `powerbi/VoltEdge Electronics.SemanticModel/`
- **Measures:** `etl/pbi_measures.py` → `_Measures` table  (documented in [`06_dax_measures.md`](06_dax_measures.md))
- **Report layout:** `etl/gen_report_visuals.py` → per-page `--from-json` bundles
- **Theme:** `powerbi/theme/VoltEdge.json`
- **One command rebuilds everything:** `cd powerbi && bash build_report.sh`

## Design identity (v2 — deep blue)

| Choice | Decision |
|---|---|
| **Tone** | Corporate — one accent family, muted everything else, quiet gridlines |
| **Palette** | Deep blue `#123E6E` = current period / focus · navy `#0E2A4E` = header · amber `#D99311` = prior year / comparison · mid-blue `#2E70B0` for a second series · the rest neutral grays |
| **Signature** | Every page: a **navy logo bar** (`#0E2A4E`, 56 px) with the VoltEdge mark top-left and a `#2E70B0` accent rule beneath, the page title + two slicers (Currency, Market) on the line below, then one row of 6 KPI cards, then two content rows on the 3-30-300 detail gradient |
| **Logo** | `powerbi/assets/voltedge-logo-*.png`, generated by `etl/gen_logo.py` (a lightning-bolt mark + wordmark; light version for the navy bar, dark version for light backgrounds) |
| **Surfaces** | Page ground `#EAEFF6`; visuals are white cards, 12 px corner radius, 1 px `#DCE4EF` border, **no drop shadow** |
| **Type** | Segoe UI / Segoe UI Semibold; KPI value **32 pt** deep blue, no duplicate label, titles 13 pt semibold, axis/label 10 pt `#64707F` |
| **Charts** | Axis titles off, category gridlines off, value gridlines `#EAEFF6`, legends top-center no title, line stroke 2 px no markers; **time axes sorted oldest→newest** (model `sortByColumn` + explicit visual sort) |
| **Tables** | No vertical gridlines, no row banding, header on `#EAEFF6` — whitespace separates rows |

The theme owns all of the above; visuals carry almost no local overrides, so a rebrand is a
one-file change. `pbir theme validate` passes.

If the curated data lives elsewhere, change the one parameter `pDataFolder` (Transform
data → Edit parameters) and refresh.

## Model at a glance

- **28 data tables** (16 dims + 12 facts) + `_Measures` + two disconnected helper tables
  (`Reporting Currency`, `Funnel Stage`).
- **65 relationships**, all single-direction many-to-one from fact to dimension.
  `dim_date` joins each fact on its primary date key (active); secondary date roles
  (ship, delivery, due, receipt, paid…) are **inactive** relationships activated inside
  specific measures with `USERELATIONSHIP`.
- **Reporting-currency selector** — the disconnected `Reporting Currency` slicer drives
  `[FX Rate to Reporting Currency]`; the `(Rpt)` measures multiply the USD base by it.
  Default is USD.
- **Comparable Base** — `dim_market[is_comparable_base]` (US) gives the like-for-like cut;
  `[Net Revenue (Comparable, Dynamic)]` recomputes the eligible market set from the
  visible date range.

## Reading the numbers

- **Contribution Margin** = Gross Profit − Marketing − Shipping Cost − Payment Fees −
  merchant financing. It runs **near break-even in normal months (~−2 %)** and dips hard
  in the Q4 promo pushes (~−13 %), where discount depth cuts gross margin to ~7 % while
  marketing stays high. Blended ≈ −5 %. The **CM bridge waterfall** on the Executive
  Summary shows exactly where the money goes; the monthly CM % trend shows the seasonality.
  Returns are netted correctly — the COGS of restocked returns is credited back (a
  ~$2 M swing versus naively subtracting only the refund).
- **Revenue Booked vs Cash Received** — Booked is recognised at order date; Cash is when
  each settlement tranche is actually paid. The gap (~5–7 % of cumulative revenue) is the
  **receivables float**: card settlement lag, an 8 % processor rolling reserve released at
  +90 days, and Brazilian instalments spread over months. Shown as **cumulative** lines on
  Sales Performance so the widening wedge is visible.
- **Acquisition is not all paid** — ~62 % of new customers come through paid channels,
  ~38 % organic / direct / email / referral. The *New customers by acquisition channel*
  chart on Marketing makes that explicit; Blended CAC deliberately divides total spend by
  *all* new customers.

## Pages

1280×860 canvas, 24 px margins, 16 px gutters. Every page:
**header image** (navy bar: bolt + VOLTEDGE + page title) · **slicer row** (Analysis
period date-range, Currency & Market as horizontal tiles) · **6 KPI tiles** (`kpi` visual
with a plan Goal + trend sparkline where a target exists, `card` otherwise) · **two
content rows** on the 3-30-300 detail gradient.

Every "big number + ratio" pair is a **combo chart** — magnitude as bars, ratio as a line
on a secondary axis (sessions/CR, delivery-days/on-time, spend/ROAS, inventory-value/
weeks-of-cover, …). Time axes are sorted oldest→newest.

### 1 · Executive Summary — *are we hitting plan, is growth real, where does the money go?*
- **KPI tiles:** Net Revenue, Gross Margin %, Orders (all `kpi` w/ plan Goal + sparkline) ·
  Contribution Margin (`card`) · New Customers, Blended CAC (`kpi` w/ Goal).
- **Net revenue by month — CY vs PY** (line).
- **Budget scorecard** (table): each planned metric — actual, target, variance %.
- **Contribution margin bridge** (waterfall): Gross Profit → −Marketing → −Shipping →
  −Payment Fees → −Financing → CM. Answers *"why is CM where it is?"*.
- **Net revenue by market — CY vs PY** (column): the expansion step-ups.

### 2 · Sales Performance
- KPI tiles: Net Revenue, **Orders**, AOV, Gross Margin %, Discount Rate %, Units/Order.
- **Net revenue (bars) & discount rate (line) by month** (combo).
- **Net revenue by category** (bar).
- **YoY revenue change by category** (waterfall) — PVM detail in the `07 …` measures.
- **Cumulative revenue booked vs cash received** (line) — the receivables float.

### 3 · Marketing & Acquisition
- KPI tiles: Marketing Spend, Blended CAC, MER, New Customers, **% New via Paid**, ROAS.
- **On-site funnel**: Sessions → Add-to-Cart → Cart → Orders.
- **Spend (bars) & blended CAC (line) by month** (combo).
- **New customers by acquisition channel** (bar) — the paid vs organic split.
- **Spend (bars) & ROAS (line) by channel** (combo) · **Campaign performance** (table).

### 4 · Website & Digital
- KPI tiles: Sessions, Conversion Rate %, Bounce Rate %, Add-to-Cart %, Cart Abandonment %,
  Revenue / Session.
- **Sessions (bars) & conversion rate (line) by month** (combo) · **Sessions by device** (donut).
- **Revenue/session (bars) & conversion rate (line) by channel** (combo) ·
  **Sessions (bars) & conversion rate (line) by market** (combo).

### 5 · Logistics & Fulfillment
- KPI tiles: On-Time Delivery %, Avg Delivery Days, Perfect Order %, Ship Cost/Order,
  Cost Recovery %, Cash Conversion Cycle.
- **Avg delivery days (bars) & on-time % (line) by month** (combo) — monthly logistics
  stress and carrier-crisis months are now visible.
- **Carrier scorecard** (combo: days vs on-time %).
- **Working capital — DIO / DSO / DPO / CCC by month** (column).
- **Company cash flow** (line): settlements in vs supplier + marketing out.

### 6 · CRM & Customer
- KPI tiles: Customers with Orders, Repeat Rate %, Avg Orders/Customer, CLV (Gross Profit),
  Churned Customers, Gold-Tier Revenue %.
- **New vs returning customer revenue by month** (line) — the two lines weave and cross.
- **Customers by status** (bar).
- **Customers acquired by cohort month & channel** (stacked column).
- **Returns by reason** (table: units, value, restock %).

### 7 · Product & Inventory
- KPI tiles: Inventory Value, Inventory Turnover, Weeks of Cover, Return Rate %, In Transit,
  Supplier Spend.
- **Gross margin % by category** (bar) · **Return rate % by category** (bar) ·
  **SKUs — revenue vs margin** (scatter).
- **Inventory value (bars) & weeks of cover (line) by month** (combo) — month-end measures,
  so *every* month renders.
- **Slow movers** (table).

## Known polish backlog (structural report is valid; `pbir validate --all` passes, no overlaps)

| Item | Note |
|---|---|
| KPI cards / slicers flagged `VISUAL_UNDERSIZED` | 192×84 px cards and 210×44 slicers are deliberately compact for the 6-up band and header strip. |
| `TOO_MANY_FIELDS` ×2 | The DIO/DSO/DPO/CCC column chart carries 4 series by design. |
| No alt text on charts yet | Add a pass of `pbir set "…general.altText"` before shipping. |
| KPI cards are plain `card` (no target/trend) | A `kpi` visual with target + trendline would be stronger on the hero metrics — model has the target measures. |
| Sub-topics dropped for density | Sales geo map, per-method installment mix, and a cohort-retention heatmap are candidates for a Phase-2 detail pass. |
| Rendering not yet verified in Desktop | `pbir` cannot drive Desktop here; some theme properties may need adjusting once seen. |

## Verifying in Power BI Desktop

1. Open `powerbi/VoltEdge Electronics.pbip`.
2. It should load the model and import the Parquet folder. If it asks, point
   `pDataFolder` at `…/VoltEdge-Electronics-Analytics/data/curated`.
3. Refresh. Check the model view for the star schema and inactive date relationships.
4. Page through the 7 report pages; confirm measures resolve (no `#ERROR` cards).
5. Report any measure or visual that misbehaves — that is the next iteration.
